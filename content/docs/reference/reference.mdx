### `DynamoModel` instance methods

| Method | Description |
|---|---|
| `.put(can_overwrite=False)` | Insert. Raises on duplicate id unless overwriting. |
| `.update(force_update_default_fields=False)` | Update only modified attributes (NoOp if nothing changed). |
| `.delete()` | Delete by id. |
| `.get_attributes_to_update()` | Returns list of attribute names that changed since load. |

### `DynamoModel` class methods

| Method | Description |
|---|---|
| `.get(id, consistent_read=True, use_cache=False)` | Fetch one row. |
| `.batch_get(ids, consistent_read=True)` | Fetch many in parallel. |
| `.query(pk_field, pk_value, sk_condition, sk_field, sk_value, ..., start_key, limit)` | Returns `(items, end_key)`. |
| `.generate(pk_field, pk_value, ...)` | Same as query but yields items one at a time. |
| `.scan(start_key, limit, filter_expression)` | Full-table scan. Avoid in hot paths. |
| `.sync_table(create_default_index=True)` | Create table + GSIs if missing. |

## Glossary

| Term | Meaning |
|---|---|
| **cmd** | Dot-separated import path used for routing: `<app>.controller.<module>.<func>`. |
| **handler** | The `aws_handler.py:handler(event, context)` function. Lambda entrypoint. |
| **controller** | `@controller`-decorated function. Receives request fields by signature injection. |
| **service** | Module of functions that orchestrate models and external services. |
| **dao** | Data-access module for queries/aggregations beyond a single model. |
| **wrapper** | A `sawsi.aws.<service>.api.*API` class. Thin boto3 wrapper. |
| **sync** | `@sync` decorator + `sync_all_models()` — the DynamoDB schema migration entry point. |
| **u_b** | Universal Bucket — automatic field always `'_'`, used as default GSI partition key. |
| **rslt_cd** | Top-level response code (`A00000`, `B*`, `U99999`). |
| **AppError** | The framework's exception type for business errors. |
| **LazyLoadedAPI** | Wrapper that defers AWS client construction until first attribute access. |
| **ScheduledTask** | Context-manager-based cron matcher for the scheduler Lambda. |
| **SparseGSI** | A GSI whose key field uses `' '` default so absent rows don't appear in the index. |

## FAQ

**Q. Can I deploy via plain `zip` instead of container images?**
A. The boilerplate ships `buildspec-lambda-{env}.yml` for that path. Use it if your project's deps are small. Most non-trivial projects benefit from the container path because `build_keeper.py` runs inside the build.

**Q. Can I run multiple cmds in a single API Gateway request?**
A. No. One request = one `cmd` = one controller. If you want batching, write a single cmd that orchestrates.

**Q. How do I cache expensive computations between Lambda invocations?**
A. Module-level globals survive within a container. For cross-container caching, use DynamoDB with a TTL.

**Q. Can I use this with FastAPI or another framework?**
A. The handler is plain Python — you can call it from anywhere. But the conventions assume the Lambda entrypoint; running under FastAPI is unusual.

**Q. How do I deal with binary uploads (images, video)?**
A. Use presigned S3 PUT URLs (`api.s3_uploads.create_presigned_url_put_object(key)`); the client uploads directly, then notifies the API the upload is done. Don't proxy binary through API Gateway.

**Q. What about WebSockets at scale?**
A. Each connection is a row in `WsConnection`. To push to N connections, iterate and call `api.apigw.post_to_connection` in parallel. For very large fan-out, queue the push to SQS and let workers fan out.

## Versioning

The library version is in `setup.py`. Current series is `20.x`. Patch releases are backward-compatible; minor releases may add deprecation warnings.

To upgrade:

```bash
pip install -U sawsi
```

Then re-read your project's `api.py` against the new `sawsi_boilerplate/api.py` to spot any new wrappers worth adopting.
