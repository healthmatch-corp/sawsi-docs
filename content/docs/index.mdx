**sawsi** (simple-aws-interface) is a Python framework for shipping AWS Lambda backends without re-inventing the boring parts. It bundles a `cmd`-based router, a Pydantic-backed DynamoDB ORM, lazy-loaded AWS service wrappers, and an opinionated deploy flow into a single coherent stack.

This handbook covers the framework from first principles down to deployment-day checklists. It is split into four arcs:

## Who this is for

You are building a serverless backend on AWS, in Python, and you want:

- A flat **`cmd` → controller** API surface instead of REST path matching.
- A DynamoDB ORM that treats GSIs and sparse indexes as first-class.
- A way to share a single AWS resource pool (`api.py`) across many Lambda triggers — API Gateway, SQS, EventBridge, S3, WebSocket, and webhook receivers — without duplication.
- Container-image deploys that initialize tables/buckets/indexes idempotently on every release.

If that is the shape of your project, this is the manual.

## A 30-second tour

```python title="main/aws_handler.py"
@aws_handler_wrapper(use_traceback=False, error_receiver=slack_notify)
def handler(event, context):
    body = handler_util.get_body(event, context)
    body['source_ip'] = handler_util.get_source_ip(event, context)
    body['user'] = _resolve_user(body)
    cmd = body.pop('cmd')
    return router(cmd, body, {}, allowed_cmd_prefixes=['main.controller'])
```

```python title="main/controller/user.py"
@controller
def get_profile(user, **kwargs):
    if user is None:
        raise errs.no_session
    return {'name': user.name, 'birth': user.birth}
```

```python title="main/model/user.py"
@sync
class User(DynamoModel):
    __dynamo__ = api.dynamo
    _table = 'user'
    _indexes = [('phone', None), ('google_social_id', None)]

    name: str
    phone: str = ' '              # sparse GSI: blank instead of None
    google_social_id: str = ' '
```
