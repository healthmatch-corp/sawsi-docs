빈 디렉터리에서 `cmd` 요청에 응답하는 람다 함수까지 가는 가장 짧은 경로예요.

## 0. 사전 요구

- Python 3.12 (현재 람다 런타임).
- ECR 리포지토리, Lambda 함수, IAM 역할, DynamoDB 테이블을 만들 수 있는 권한이 있는 AWS 계정.
- 배포할 계정용 자격증명으로 설정된 AWS CLI.
- Docker (컨테이너 이미지 배포 경로용).

<Callout>
AWS 접근 없이도 개발과 코드 작성이 가능해요. 클라우드 자격증명이 필요한 것은 배포 단계뿐이에요 ([배포](/docs/deployment/deployment) 참고하세요).
</Callout>

## 1. CLI 설치

```bash
pip install sawsi
```

라이브러리를 설치하고 PATH에 `awsi` 명령을 등록해요.

## 2. 프로젝트 스캐폴딩

```bash
awsi init myproject main
```

생성되는 구조예요:

```
.
├── api.py                   # AWS 서비스 클라이언트 싱글턴 풀
├── config.py                # env, region, build 플래그, 환경별 상수
├── errs.py                  # 이 프로젝트 고유의 AppError 인스턴스
├── build_keeper.py          # 배포마다 1회 실행: 테이블 sync, 버킷 init
├── requirements.txt
├── Dockerfile               # Lambda가 쓰는 컨테이너 이미지
├── buildspec-{lambda,docker}-{dev,prod}.yml
├── aws_iam_policy_{dev,prod}.json
└── main/
    ├── aws_handler.py        # API Gateway용 Lambda 진입점
    ├── controller/
    │   └── auth.py           # 예시 @controller
    ├── service/
    │   └── auth_service.py
    └── model/
        └── sample_user.py    # 예시 DynamoModel
```

`api.py`를 열고 `{{project}}` 자리표시자가 `myproject`로 치환되었는지 확인해 주세요 (CLI가 자동으로 해 주지만 검증해 보면 좋아요).

## 3. 생성된 핸들러 읽기

```python title="main/aws_handler.py"
from sawsi.shared import handler_util
from sawsi.handler.router import router
import errs

@handler_util.aws_handler_wrapper(
    error_receiver=lambda errmsg: print(errmsg),
    content_type='application/json',
    use_traceback=True,
    ignore_app_errors=[errs.no_session],
)
def handler(event, context):
    body = handler_util.get_body(event, context)
    headers = handler_util.get_headers(event, context)
    body['source_ip'] = handler_util.get_source_ip(event, context)
    cmd = body.pop('cmd')
    return router(cmd, body, headers, allowed_cmd_prefixes=['main.controller'])
```

주목할 세 가지예요:

- `@aws_handler_wrapper`가 함수를 감싸 어떤 리턴값이나 `AppError`든 적절한 모양의 API Gateway 응답으로 변환해 줘요.
- `router()`가 요청 본문의 `cmd` 필드에 따라 디스패치해요.
- `allowed_cmd_prefixes`는 보안 게이트예요 — `main.controller.*`로 시작하는 `cmd`만 허용해요.

## 4. 첫 컨트롤러 추가

```python title="main/controller/hello.py"
from sawsi.handler.controller_decorator import controller

@controller
def say_hello(name: str = 'world', **kwargs):
    return {'message': f'안녕, {name}!'}
```

끝이에요. 등록도 없고 라우팅 테이블도 없어요. `@controller` 데코레이터가 함수를 `module.function_name` 키로 레지스트리에 추가하고, 라우터가 찾아내요.

이 컨트롤러에 도달하는 요청 모양이에요:

```json
{
  "cmd": "main.controller.hello.say_hello",
  "name": "sawsi"
}
```

## 5. 로컬 실행

작은 Flask 어댑터를 만들어 주세요 (프로덕션 프로젝트에서 사용 중인 한 예 — [hm-serverless `local_server_main.py`](https://github.com/syc-weapon/hm-serverless/blob/master/local_server_main.py) 참고해 보세요):

```python title="local_server.py"
from flask import Flask, request, jsonify
import json, time
import os
os.environ.setdefault('env', 'dev')
from main.aws_handler import handler

app = Flask(__name__)

@app.post('/')
def root():
    event = {
        'body': json.dumps(request.get_json()),
        'headers': dict(request.headers),
        'requestContext': {'requestTimeEpoch': int(time.time() * 1000)},
    }
    return jsonify(handler(event, {}))

if __name__ == '__main__':
    app.run(port=8000, debug=True)
```

```bash
env=dev python local_server.py
```

그리고:

```bash
curl -X POST http://localhost:8000 \
  -H 'Content-Type: application/json' \
  -d '{"cmd": "main.controller.hello.say_hello", "name": "sawsi"}'
```

다음과 같은 응답을 받게 돼요:

```json
{
  "rslt_cd": "A00000",
  "rslt_msg": "요청 성공",
  "duration": 0.012,
  "message": "안녕, sawsi!"
}
```

`rslt_cd`/`rslt_msg`/`duration` 봉투는 `@aws_handler_wrapper`가 추가해 준 거예요. 전체 코드 체계는 [에러 & 결과 코드](/docs/architecture/errors)를 참고해 주세요.

## 6. 방금 일어난 일

위에서 아래로 살펴볼게요:

1. Flask 어댑터가 가짜 API Gateway `event` dict를 만들고 `handler(event, {})`를 호출해요.
2. `@aws_handler_wrapper`가 본문을 추출하고, 호출 시간을 재고, 응답 봉투를 준비해요.
3. 핸들러가 `router(cmd, body, headers, allowed_cmd_prefixes)`를 호출해요.
4. 라우터가 `cmd`가 `main.controller.`로 시작하는지 검증한 뒤, 컨트롤러 레지스트리에서 `main.controller.hello.say_hello`를 검색해요.
5. 라우터가 `say_hello`의 시그니처를 inspect하고, `body`의 `name` 키와 매칭해서 `say_hello(name='sawsi')`를 호출해요.
6. 리턴 dict가 봉투에 합쳐져 반환돼요.

이게 요청 라이프사이클 전체예요. 이 핸드북의 나머지는 그 주변의 박스를 채우는 작업이에요.
