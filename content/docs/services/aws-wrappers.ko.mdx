sawsi를 통해 사용되는 모든 AWS 서비스는 `sawsi.aws.<service>.api` 아래의 `*API` 클래스로 노출돼요. 모두 균일한 모양을 공유해요 — 생성자는 리소스 식별자와 region을 받고, 메서드는 직접적인 동사(`upload_file`, `send_message`, `get_secret_value`)예요. 그리고 모두 `LazyLoadedAPI`로 감싸서 `api.py` 안에 모아 둬요.

이 페이지가 각 래퍼의 레퍼런스예요 — 무엇인지, `api.py`에서 어떻게 선언하는지, init 시 무엇을 하는지, 그리고 알아 둬야 할 함정을 정리해 뒀어요.

## api.py 패턴

모든 래퍼는 `api.py`에 정확히 한 번씩 들어가요:

```python title="api.py"
from sawsi.aws.dynamodb.api import DynamoDBAPI
from sawsi.aws.s3.api import S3API
from sawsi.aws.locking.api import LockingAPI
from sawsi.aws.firehose.api import Firehose
from sawsi.aws.ses.api import SESAPI
from sawsi.aws.sqs.api import SQSAPI
from sawsi.aws.sms.api import SMSAPI
from sawsi.aws.secrets_manager.api import SecretManagerAPI
from sawsi.aws.apigateway.api import APIGatewayManagement
from sawsi.shared.class_util import LazyLoadedAPI
import config

env = config.env
project_name = 'myproject'
region = config.region

dynamo:         DynamoDBAPI         = LazyLoadedAPI(DynamoDBAPI,         f'{env}-{project_name}',                                                              region=region)
s3_public:      S3API               = LazyLoadedAPI(S3API,               f'{env}-{project_name}-public',                                                       region=region)
s3_uploads:     S3API               = LazyLoadedAPI(S3API,               f'{env}-{project_name}-uploads',                                                      region=region)
locking:        LockingAPI          = LazyLoadedAPI(LockingAPI,          f'{env}-{project_name}-locking',                                                      region=region)
firehose_log:   Firehose            = LazyLoadedAPI(Firehose,            f'{env}-{project_name}', f'{env}-{project_name}-firehose-log', 'log',                 region=region)
ses:            SESAPI              = LazyLoadedAPI(SESAPI,              region=region)
sqs:            SQSAPI              = LazyLoadedAPI(SQSAPI,              f'https://sqs.{region}.amazonaws.com/<account>/{env}_{project_name}_queue',           region=region)
sms:            SMSAPI              = LazyLoadedAPI(SMSAPI,              region_name='us-east-1')   # SMS는 us-east-1에서만 발송돼요
secret_manager: SecretManagerAPI    = LazyLoadedAPI(SecretManagerAPI,    f'{env}/{project_name}',                                                              region=region)
apigw:          APIGatewayManagement= LazyLoadedAPI(APIGatewayManagement, endpoint_url='https://<api-id>.execute-api.<region>.amazonaws.com/<stage>',          region=region)
```

타입 어노테이션은 감싸진 클래스를 사용해서 IDE 자동완성이 완전하게 동작하고, 런타임 값은 속성 접근을 위임하는 `LazyLoadedAPI`예요.

## S3 — `S3API`

```python
s3_public.init_s3_bucket(acl='public-read')     # build_keeper.py에서 호출해요
s3_public.upload_file(local_path, object_key, content_type='image/webp', acl='public-read')
url = s3_public.upload_file_and_return_url(bytes_or_path, ext='webp', content_type='image/webp')
s3_public.download_file(object_key, local_path)
s3_public.create_presigned_url_put_object(object_key, expires_in=3600)
```

컨벤션:

- **공개 vs 비공개 버킷 분리.** 공개 버킷은 웹에서 읽을 수 있는 자산(아바타, 생성된 썸네일)을 담고, 비공개 버킷은 처리 전 사용자 업로드를 담아요.
- **`init_s3_bucket(acl='public-read')`는 `build_keeper.py`에서 한 번만 호출해요.** 함수는 멱등해요.
- **Presigned URL은 단기로 써요.** 요청마다 생성하고, 캐시하지 마세요.

## SQS — `SQSAPI`

```python
api.sqs.send_message(json.dumps({'type': 'queue_receiver.controller.x.y', 'body': {...}}))
```

래퍼는 인스턴스마다 고정된 `queue_url`을 가져요. 두 번째 큐에 보내야 한다면 두 번째 `LazyLoadedAPI(SQSAPI, other_url, ...)`를 선언하면 돼요. 수신은 큐 람다의 `aws_handler.py`가 `event['Records']`에서 읽어요.

## SES — `SESAPI`

```python
api.ses.send_email(
    sender='no-reply@mydomain.com',
    recipient='user@example.com',
    subject='환영합니다',
    body_text='평문 본문',
    body_html='<html>...</html>',
)
```

사전 요구사항: 발송 도메인(또는 발송에 쓰는 이메일 각각)이 **SES에 verify** 되어 있어야 해요. 샌드박스 밖의 SES는 별도로 AWS 지원 요청을 넣어야 해요.

## SMS — `SMSAPI`

```python
api.sms.send_sms(phone_number='+82-10-...', message='Code: 123456')
```

SNS Transactional SMS 위에 구현돼 있어요 — `us-east-1`에서만 사용할 수 있어요. 프로젝트 나머지 region과 무관하게 래퍼를 `region_name='us-east-1'`로 선언해 주세요.

국제 SMS 라우팅과 가격 캡은 AWS 계정 레벨 설정이라 한 번만 구성하면 돼요.

## Locking — `LockingAPI`

DynamoDB 기반 분산 락이에요. 컨텍스트 매니저 API로 써요.

```python
# api.py
locking = LazyLoadedAPI(LockingAPI, f'{env}-{project}-locking', region=region)

# build_keeper.py
api.locking.init_table()

# 코드에서
with api.locking.lock('register_phone_+82-10-1234-5678', max_alive_ts=30, max_retries=3, wait_time=2):
    do_critical_section()
```

`max_retries × wait_time` 초 안에 락을 얻지 못하면 컨텍스트 매니저가 `RuntimeError`를 raise해요. 호출자가 사용자 대면이면 `AppError`로 번역해 주세요:

```python
try:
    with api.locking.lock(...):
        ...
except RuntimeError:
    raise errs.lock_busy
```

## Firehose — `Firehose`

Kinesis Firehose를 통한 S3로의 구조화 로깅이에요.

```python
# api.py
firehose_log = LazyLoadedAPI(Firehose, stream_name, bucket_name, key_prefix, region=region)

# build_keeper.py
api.firehose_log.init()         # 스트림 + IAM 역할을 생성하고, 이후 IAM 전파를 위해 ~4초 sleep해요

# 코드에서 (핫패스)
api.firehose_log.put_record(json.dumps({...}))

# 나중에 읽기
for log, key in api.firehose_log.generate_log_json_list_and_key(key_start_after=cursor):
    process(log)
```

`init()`의 4초 sleep은 **옵션이 아니에요** — IAM 역할 전파는 최종적 일관성이라, 생성 직후 첫 `put_record`는 sleep이 없으면 실패해요.

레코드는 Firehose가 최대 5분 동안 버퍼링한 뒤 S3에 안착해요 — 방금 쓴 레코드를 곧바로 읽으려 하지 마세요.

## SecretsManager — `SecretManagerAPI`

```python
secret_manager = LazyLoadedAPI(SecretManagerAPI, f'{env}/{project}', region=region)

key = api.secret_manager.get_secret_value('open_ai_secret_key')
```

래퍼가 첫 읽기 후 **복호화된 시크릿 값**을 메모리에 캐시해요. 두 가지 의미가 있어요:

- **저렴해요.** KMS 복호화는 요청마다 청구돼서 — 캐시가 핫패스에서 비용을 줄여 줘요.
- **회전 후엔 stale해요.** AWS에서 시크릿이 회전되어도 람다 컨테이너 캐시는 무효화되지 않아요. 다음 콜드스타트가 새 값을 집어 들지만, 기존 warm 컨테이너는 재활용될 때까지 옛 값을 계속 써요 (분~시간 단위).

즉각적인 회전이 중요하다면 재배포로 컨테이너를 강제 재활용해 주세요.

## API Gateway Management — `APIGatewayManagement`

연결된 클라이언트로 임의의 람다에서 WebSocket을 푸시해요.

```python
apigw = LazyLoadedAPI(APIGatewayManagement, endpoint_url='https://<ws-api-id>.execute-api.<region>.amazonaws.com/<stage>', region=region)

api.apigw.post_to_connection(data=json.dumps({...}), connection_id=conn_id)
```

엔드포인트 URL은 **환경별로 달라요** — dev WebSocket API와 prod의 `execute-api` 호스트가 다르거든요. 여기처럼 `api.py`에 하드코딩해도 괜찮고, 필요하면 `if env == 'prod'`로 감싸도 돼요.

## SNS — `SNSAPI`

```python
api.sns.send_message(topic_arn, message)
```

pub/sub 팬아웃에 써요. SMS는 별도 `SMSAPI`로 분리된 특별 케이스예요.

## SSM — `SSMAPI`

```python
api.ssm.run_commands(instance_id, ['systemctl restart my-service'])
```

람다에서 EC2 인스턴스를 제어할 때 써요. 완전 서버리스 구성에선 드물게 등장해요.

## Lambda client — `LambdaAPI`

```python
api.lambda_client.invoke(function_name, payload)
api.lambda_client.create_event_source_mapping(function_name, event_source_arn, ...)
api.lambda_client.update_lambda_code(function_name, s3_bucket, s3_key, publish=False)
```

대부분의 프로젝트에선 이걸 동기 cross-function 호출(SQS가 너무 비동기일 때)과 자체 관리 배포 스크립트에 써요.

## CloudWatch Logs — `LogsAPI`

```python
events = api.logs.get_log_events(log_group_name, log_stream_name)
```

자기 함수들의 로그를 읽는 어드민 도구에 유용해요.

## OpenSearch — `OpenSearchAPI`

```python
api.opensearch.run('POST', '/myindex/_search', body={'query': {'match_all': {}}})
api.opensearch.put_document('myindex', doc_id, document)
```

OpenSearch 도메인에 대한 SigV4 서명 HTTP 요청을 보내요. 인덱스/매핑은 직접 관리해야 해요.

## Bedrock — `BedrockAPI`

```python
resp = api.bedrock.converse(
    model_id='anthropic.claude-haiku-4-5-20251001',
    messages=[{'role': 'user', 'content': [{'text': 'hello'}]}],
    system='You are a helpful assistant.',
    max_tokens=512,
)
```

고수준 `converse()`(권장)와 저수준 `invoke_model()` 모두 사용할 수 있어요. Vector KB와 SearchEngine 이야기는 [AI / Vector / Search](/docs/services/ai-vector-search) 챕터를 참고해 주세요.
